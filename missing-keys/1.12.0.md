# Translation handoff: new keys in Hearth & Herald 1.12.0

1.12.0 adds two pieces: a bulk path for raising several veterans to officer rank
at once (shape them alike with one commission, plus one calling when Skill build
at promotion is on, or walk each one individually as before), and a seat at the table for every herald, not just the
Master. Seated heralds now stand in the lord's hall of your clan home alongside
the Master Herald, instead of being a line item on a menu with nothing to show
for it.

Russian carries a full first-pass draft of all 25 new keys (game text and
settings). The eight other community languages (BR/CNs/DE/ES/FR/IT/PL/TR) carry
a first-pass draft of the 2 new settings keys only; their game text still falls
back to English until translated. If a draft reads wrong in your language,
correct it and open a pull request (or post it on Nexus or Discord).

Terms of art to keep consistent: commission / commissioning (granting an
officer rank), intake (the group of veterans being raised together), Thegn /
Marshal / Castellan / Caravan Master (the four callings, unchanged from
1.11.0), and Herald (an officer who holds one of the herald offices - Exchequer,
Watch, Muster, Arms - and is barred from party, caravan, and governor duty).

Two rules that break the game if ignored: keep every {VARIABLE} token exactly
(for example {COUNT}, {TOTAL}, {NAME}, {TRACK}, {HELD}, {CAP}, {ROOM},
{PICKED}); and do NOT use plural blocks like {?(X != 1)|s|} - they blank the
whole string, so translate the explicit _1 / _n key pair instead (none of this
release's keys need that pair; English already reads correctly for any count).

## Changed English text in 1.12.0, 1 existing settings key

The promotion cap's hint now mentions the bulk intake. RU is updated; the
eight community languages still carry the older text, so update yours from this:

```xml
<string id="hh_mcm_promotion_max_per_review_hint" text="How many veterans you can ennoble in one review. Over-killing a troop type banks several elevations, so you can promote more than one of the same type at once (like Distinguished Service). Raise it when you are building a corps: pick a whole intake at once and shape them with one commission (and one calling, when Skill build at promotion is on)." />
```
